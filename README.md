# Overview

This repository contains the `R` and `C++` source code and replication materials 
required to reproduce the simulation studies, application results, figures, and 
tables for the EDPqrl project associated with the papers

*"Bayesian Nonparametric Causal Inference for Quantile Residual Life: 
Application to Alzheimer’s Disease."*  

---

# Replication Materials & File Manifest

The replication materials are organized according to their purpose and 
computational demands.

### 1. Core Source Code
* **`EDPqrl_r.R`** and **`EDPqrl_r.cpp`**
* **Description:** These files contain the main source code for posterior 
computation, MCMC sampling, and post-processing used throughout the project. 
The `R` script provides the main functions used in the replication files, while 
the `C++` file contains computational routines used to improve efficiency.

### 2. Simulation Replication (HPC Required)
* **`EDPqrl_replication_SIM.R`** and **`batch_replication_SIM.sbatch`**
* **Description:** These files reproduce the simulation study results reported in 
the manuscript. Because the simulation experiments are computationally intensive, 
they are intended to be run on a High-Performance Computing (HPC) cluster. The 
provided `.sbatch` file is configured for submission through a Slurm-based HPC 
environment.
* **Execution Time:** **[WARNING: LONG-RUNNING]** These simulations may require 
substantial computing time depending on the number of Monte Carlo replications 
and posterior sampling settings.

### 3. Simulation Output Files
* **`Results/`**
* **Description:** This folder contains the simulation output files saved as 
`.txt` files. These results are generated by running

      sbatch batch_replication_SIM.sbatch

  which executes **`EDPqrl_replication_SIM.R`** in the HPC environment.

### 4. Simulation Summary and Table Generation
* **`EDPqrl_replication_check.R`**
* **Description:** After the simulation jobs are completed, this script can be 
used to collect the output stored in the `Results/` folder, summarize the 
results, and generate the tables reported in the manuscript, including 
LaTeX-ready output when applicable.
* **Execution Time:** Moderate.

### 5. ADNI Application Replication
* **`EDPqrl_replication_ADNI.R`**
* **Description:** This script reproduces the application analysis based on the 
Alzheimer’s Disease Neuroimaging Initiative (ADNI) data, including the main 
application results, figures, and related summaries presented in the paper.
* **Execution Time:** Designed to run on a personal laptop or standard desktop 
environment.

# Instructions for Execution

1. **Ensure all files are in the same working directory.**

2. **Compile and load the core source code before running replication scripts.**  
   Make sure that `EDPqrl_r.R` and `EDPqrl_r.cpp` are available in your working 
   directory so that the main functions can be sourced and compiled properly.

3. **To reproduce the ADNI application results:** Open `R` or `RStudio`, set the 
   working directory to this folder, and run

       source("EDPqrl_replication_ADNI.R")

4. **To reproduce the simulation study results (HPC environment):** If you have 
   access to a Slurm-based HPC cluster, submit the simulation job from the 
   terminal using

       sbatch batch_replication_SIM.sbatch

5. **Simulation output files:** The simulation output generated by the HPC job is 
   saved in the `Results/` folder as `.txt` files.

6. **To summarize the simulation output and generate tables:** After the 
   simulation jobs are complete, run

       source("EDPqrl_replication_check.R")

7. **For local testing:** If you want to verify the simulation code on a personal 
   computer, open `EDPqrl_replication_SIM.R`, reduce the number of simulation 
   replications and/or MCMC iterations, and run the script locally.

---

# Notes

* The simulation replication script is intended for HPC use because of its 
  computational burden.
* The `Results/` folder stores the simulation output files generated from the 
  HPC replication job.
* The ADNI application replication script is intended to run on a personal 
  laptop or desktop.
* Users may need to adjust file paths, compiler settings, or package 
  installations depending on their local computing environment.
