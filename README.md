# Overview

This repository contains the `R` and `C++` source code and replication materials
required to reproduce the simulation studies, ADNI application results, figures,
and tables reported in the manuscript

*"Bayesian Nonparametric Causal Inference for Quantile Residual Life:  
An Application to Alzheimer's Disease."*

---

# Replication Materials and File Manifest

The replication materials are organized according to their purpose and
computational requirements.

### 1. Core Source Code

* **`EDPqrl_r.R`** and **`EDPqrl_cpp.cpp`**
* **Description:** These files contain the core functions for posterior
  computation, MCMC sampling, and post-processing used throughout the
  replication analyses. The `R` script provides the primary model-fitting and
  post-processing functions, while the `C++` file contains computational
  routines used to improve efficiency.

### 2. Simulation Replication

* **`EDPqrl_replication_SIM.R`** and **`batch_replication_SIM.sbatch`**
* **Description:** These files reproduce the simulation study reported in the
  manuscript. Because the simulation experiments are computationally intensive,
  they are intended to be run on a high-performance computing (HPC) cluster.
  The supplied `.sbatch` file is configured for submission in a Slurm-based HPC
  environment.
* **Execution Time:** **[WARNING: LONG-RUNNING]** The full simulation study may
  require substantial computing time, depending on the number of Monte Carlo
  replications, sample sizes, and posterior sampling settings.

### 3. Simulation Output Files

* **`Results/`**
* **Description:** This folder contains the simulation output files saved in
  `.txt` format. These files are generated by running

      sbatch batch_replication_SIM.sbatch

  which executes **`EDPqrl_replication_SIM.R`** in the HPC environment.

  The main simulation results using nominal 95% credible intervals are stored
  without a credible-interval suffix. Results from the supplementary analysis
  using nominal 99% credible intervals use the suffix `_level1`.

  Examples include:

  * `EDPMM_Scn1_N500.txt`
  * `DPMM_Scn4_N1500.txt`
  * `EDPMM_Scn3_N5000.txt`
  * `EDPMM_Scn3_N500_level1.txt`

### 4. Simulation Summary and Table Generation

* **`EDPqrl_replication_check.R`**
* **Description:** After the simulation jobs are completed, this script reads
  the output stored in the `Results/` folder, calculates empirical bias, root
  mean squared error, and coverage probability, and generates the simulation
  tables reported in the manuscript. LaTeX-ready versions of the tables are
  also produced.

  The script uses **`True_PSQC.txt`**, which contains the population PSQC values
  used to evaluate simulation performance. These values can be regenerated
  within the script, although the corresponding Monte Carlo calculation is
  computationally intensive.
* **Execution Time:** Moderate when `True_PSQC.txt` is supplied. Regenerating the
  population PSQC values may require substantial computing time.

### 5. ADNI Application Replication

* **`EDPqrl_replication_ADNI.R`**
* **Description:** This script reproduces the application analysis based on data
  from the Alzheimer's Disease Neuroimaging Initiative (ADNI), including cohort
  construction, posterior inference, the main application table, and the
  figures reported in the manuscript and supplementary materials.
* **Execution Time:** The analysis can be run on a personal laptop or standard
  desktop computer, but the MCMC sampling and posterior post-processing steps
  may require substantial computing time. Checkpoint files may be used to avoid
  rerunning completed stages when available.

# Data Availability

The ADNI data used in this analysis are not included in this repository. Access
to ADNI data is available to qualified researchers subject to the applicable
ADNI data-use procedures and policies at
[adni.loni.usc.edu](http://adni.loni.usc.edu/).

The ADNI application script uses data objects provided through the
**`ADNIMERGE2`** package. Users must obtain the required ADNI data access and
install the necessary package before running the application analysis.

# Instructions for Execution

1. **Place the replication files in the appropriate working directory.**

   The core source files must be accessible from the working directory used to
   run the replication scripts. File paths can be modified within the scripts
   when a different directory structure is used.

2. **Install the required R packages.**

   The replication scripts require packages for Bayesian computation, survival
   analysis, data manipulation, table generation, and figure generation. A
   working C++ compiler compatible with `Rcpp` and `RcppArmadillo` is also
   required.

3. **Compile and load the core source code.**

   Make sure that `EDPqrl_r.R` and `EDPqrl_cpp.cpp` are available in the
   specified source directory. The replication scripts load these files using

       source("EDPqrl_r.R")
       Rcpp::sourceCpp("EDPqrl_cpp.cpp")

4. **Reproduce the ADNI application results.**

   Open `R` or `RStudio`, set the working directory to the repository folder,
   and run

       source("EDPqrl_replication_ADNI.R")

   The script performs data preparation, MCMC sampling, posterior
   post-processing, table generation, and figure generation. Users may use the
   checkpoint options in the script to resume the analysis from a completed
   stage.

5. **Reproduce the simulation study in an HPC environment.**

   From a Slurm-based HPC cluster, submit the simulation array job using

       sbatch batch_replication_SIM.sbatch

   The batch file executes `EDPqrl_replication_SIM.R` for the specified
   simulation settings and Monte Carlo replication IDs.

6. **Locate the simulation output files.**

   The simulation output generated by the HPC jobs is saved in the `Results/`
   folder in `.txt` format.

7. **Summarize the simulation results and generate the manuscript tables.**

   After all required simulation jobs have completed, run

       source("EDPqrl_replication_check.R")

   This script reads the simulation output files, calculates the reported
   performance measures, and creates the main-text and supplementary simulation
   tables.

8. **Perform a local simulation test.**

   To verify that the simulation code runs on a personal computer, open
   `EDPqrl_replication_SIM.R` and temporarily reduce the MCMC iterations,
   posterior Monte Carlo sample size, and number of simulation replications.
   The full settings should be restored when reproducing the results reported
   in the manuscript.

---

# Notes

* The full simulation replication is intended for HPC use because of its
  computational burden.
* The `Results/` folder stores the simulation output generated by the HPC jobs.
* Main 95% credible-interval results and the supplementary \(N=5000\) results
  are saved without a level suffix.
* Supplementary 99% credible-interval results are saved using the suffix
  `_level1`.
* The ADNI application can be run on a personal laptop or desktop computer, but
  the full MCMC and post-processing procedures may be time-consuming.
* The ADNI data are not redistributed with this repository.
* Users may need to adjust file paths, compiler settings, package installations,
  Slurm settings, and computing resources for their local environment.
